# 音声ファイル生成ガイド

レッスン用の音声ファイル（WAV）の生成・管理に関するガイドです。

## 音声生成方法: Gemini TTS

すべてのレッスン音声は **Gemini TTS**（`gemini-2.5-flash-preview-tts`、Zephyr音声）で生成しています。

### 生成スクリプト

| スクリプト | 対象 | 用途 |
|-----------|------|------|
| `scripts/generate-audio-n4-n2.py` | N4/N3/N2（lesson-011〜025） | 現在の正式な生成スクリプト |

> N5（lesson-001〜010）もGemini TTSで生成済みですが、専用スクリプトは現存しません。
> 新規追加・再生成時は `generate-audio-n4-n2.py` のパターンに合わせてください。

### 実行方法

```bash
# 依存パッケージのインストール
pip install google-genai python-dotenv

# .env に GEMINI_API_KEY を設定済みであること
# 実行
python scripts/generate-audio-n4-n2.py
```

### TTS設定

| 項目 | 値 |
|------|-----|
| モデル | `gemini-2.5-flash-preview-tts` |
| 音声 | `Zephyr`（プリセット音声） |
| 出力形式 | WAV（PCM、24000Hz、16bit、モノラル） |
| レート制限対策 | API呼び出し間に2秒待機 |

### レベル別の話速指示（プロンプト）

| レベル | 話速指示 |
|--------|---------|
| N5 | 丁寧にゆっくり話してください。 |
| N4 | 丁寧にゆっくり話してください。 |
| N3 | やや自然な速度で話してください。 |
| N2 | 自然な会話速度で話してください。 |

### プロンプトテンプレート

```
あなたは日本語の先生です。以下のテキストを読み上げてください。
{話速指示}
句読点では適切な間を取ってください。

テキスト:
{読み上げテキスト}
```

### TTS入力テキストの表記ルール

| レベル | 表記方式 | 理由 |
|--------|---------|------|
| N5/N4 | ひらがな（分かち書き） | 正確な読みの保証 |
| N3/N2 | 漢字交じり | 自然なイントネーション |

## 新規レッスン追加時の手順

1. `src/data/lessons.ts` にレッスンデータを追加
2. `scripts/generate-audio-n4-n2.py` の `LESSONS` 配列にエントリを追加
   - `id`: レッスンID（`lesson-{NNN}`）
   - `level`: JLPTレベル（`N5` / `N4` / `N3` / `N2`）
   - `text`: TTSに渡すテキスト（N5/N4はひらがな、N3/N2は漢字交じり）
   - `speed_instruction`: レベルに応じた話速指示
3. スクリプトを実行して音声を生成
4. 生成されたWAVファイルを対応するレベルディレクトリに配置

### 出力先のルール

```
public/audio/{LEVEL}/lesson-{NNN}.wav
```

例: `public/audio/N4/lesson-026.wav`

## 音声ファイルの仕様

| 項目 | 値 |
|------|-----|
| 形式 | WAV（PCM） |
| サンプルレート | 24000Hz |
| ビット深度 | 16bit |
| チャンネル | モノラル |

## 音声品質のガイドライン

- 超初級者向けなので **ゆっくり・はっきり** した発音が重要
- 句読点で適切な間を入れる（プロンプトで指示済み）
- レベルが上がるにつれて自然な速度に近づける
